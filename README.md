# SP Company — Mobile App (prototype)

Interactive multi-screen mobile app prototype for SP Company Ltd (Japanese used-vehicle export marketplace).

**Live demo:** https://hgs-pro.github.io/sp-mobile-app/

- Built from the locked SP component library (Uber Move, #276EF1) in `sp-lib.css`.
- Grounded in the SP web app codebase.
- Screen sets: Sign Up flow, Log In flow (more added over time).
- Tap **⚏ All screens** to jump to any screen.

Open `index.html` in a browser, or visit the live demo above.
